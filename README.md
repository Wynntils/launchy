# Apps
- [Olinus Majestic Overhaul Installer](https://discord.gg/olinus-corner-778965021656743966) - This simple app will let you install the Olinus Majestic Overhaul modpack with a simple click, for the simplest, click and play solution, use this. You can find it on Olinus' Discord server.
- [Modrinth App](https://modrinth.com/app) - Launcher made by Modrinth, allows for easy manipulation of multiple instances which allows you to keep your mods separated and organised. With it you can install and update singular mods like Wynntils or whole modpacks mentioned below. Has access to any content on Modrinth. A gif included below shows how quick and easy it is to install Wynntils with this app.
- [Prism Launcher](https://prismlauncher.org/) - Simplistic but feature rich, everything in this launcher is straight to the point. With it you can manage multiple instances which will easly allow you to keep mods separated and organized. You can install singular mods like Wynntils or also whole modpacks mentioned below. Has access to majority of main content providers which include Modrinth, Curseforge or FTB.

# Unofficial Modpacks
*Note: Wynntils is a singular mod and there are no official modpacks, projects mentioned below are made by community only, there is a chance that you may encounter specific issues not caused by Wynntils in such modpacks*
- [Olinus Majestic Overhaul](https://discord.gg/olinus-corner-778965021656743966) - Modpack featuring many mods, including optimisation and game enhancements. You need to use dedicated installer app mentioned above to install it. You can find it at Olinus' Discord server.
- [Wynnic Enchantments](https://modrinth.com/modpack/wynnicenchantments) - Feature rich experiance. Contains lots of mods from optimization through enhancements to new content including custom made content. Made by <@327154728708603906>  
- [Wynncraft Plus](https://modrinth.com/modpack/wynncraft-plus) - Simplistic modpack containing common optimization mods as well as dedicated Wynncraft mods. Maintained by <@291661685863874560>
